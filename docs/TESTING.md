# 测试说明

## 核心单元测试（QEMU）

`tests/esp_test_app` 把 `components/desk_buddy_core` 和 `tests/test_desk_buddy_core.cpp` 编译成独立的 ESP32-S3 应用，在 QEMU 中运行。串口输出 `TEST_RUNNER_EXIT_CODE=<n>` 后，[run_qemu_tests.py](../tests/run_qemu_tests.py) 以该值退出。

```sh
idf.py -C tests/esp_test_app set-target esp32s3
idf.py -C tests/esp_test_app build
cd tests/esp_test_app/build
python -m esptool --chip esp32s3 merge-bin --pad-to-size 4MB -o qemu_flash.bin @flash_args
cd ../../..
python tests/run_qemu_tests.py --qemu qemu-system-xtensa --flash-bin tests/esp_test_app/build/qemu_flash.bin
```

QEMU 可用 `python $IDF_PATH/tools/idf_tools.py install qemu-xtensa` 安装。

## 实机自动回归

构建时设置 `-D DESK_BUDDY_DEVICE_SMOKE=ON`：

```sh
idf.py -D DESK_BUDDY_DEVICE_SMOKE=ON build
```

诊断版上电后通过桌面应用入口、正常命令队列和应用返回键循环 30 轮，共 210 次打开、绘制和关闭。模拟操作在处理真实触控的 LVGL 任务中执行。覆盖内容：

- 随机实验室从宫格进入硬币页，首轮读到 QMI8658 样本后注入摇晃事件，后续轮次点击舞台，检查硬币结果和两级返回。
- 木鱼连续 50 次计数。
- 时间工具三张实时状态卡轮巡，上下班编辑器保存与取消。
- 系统设置四张状态卡轮巡，含电源菜单开关、实体按键说明页，以及 RTC 分钟步进长按后松手无额外步进。
- 时间工具与设置先从子页返回首页，检查卡片数量和返回键文案，再退出应用。

诊断版使用独立的 `desk_buddy_test` NVS 命名空间，并禁用开机自动联网。通过时串口出现 `DB:DeviceTest` 的 `END passed=210 expected=210`，中间没有 `FAIL`、重启或显示传输失败。`DB:DisplayBench` 同时记录各刷新场景的耗时：`first_to_done_us` 为首次提交到末次 SPI 传输结束，`total_us` 从 LVGL 开始刷新计时。

常规版构建须设置 `-D DESK_BUDDY_DEVICE_SMOKE=OFF`。动画撕裂、触感和外设行为需要在实体屏幕上检查，见下方清单。

## 实机检查清单

### 烧录与首次启动

- 合并镜像从 `0x0` 烧录，或分段烧录后，冷启动直接进入摸鱼搭子桌面。
- 480×480 AMOLED 显示清晰，无撕裂、偏色、中文缺字、方块或裁切。
- 冷启动进入第 1 页，3×2 六个应用图标和底部语录排版完整。向右滑到负一屏，向左滑到设置入口页，页码指示和滑动方向正确。
- 顶栏时间和电量完全显示在圆角安全区内，设置入口页只显示设置图标。快速和慢速横滑均在松手后切换一页。
- 负一屏时钟、木鱼、下班进度、今日运势和吃啥卡片可点击，横滑经过卡片时不触发点击。
- 点击桌面应用名称可进入应用，应用顶部返回键可点按。2048 棋盘内上滑执行游戏操作，从底部短横线上滑返回桌面。

### 应用与设置

- 随机实验室以五项工具的大宫格启动。逐项进入工具页，点按主卡片中心和边缘均能触发。吃啥分类键依次循环五类，骰子颗数键按 1、2、3 循环，动画期间连续点按不会叠加。
- 从工具页点「列表」回大宫格，再点「返回」回桌面；从工具页底部短横线上滑直接回桌面。
- 连续抛硬币直到出现两种结果，翻转期间无横向断层，正反面与计数一致。随机数页切换最小值和最大值焦点，四颗步进键短按一次只变动一步，长按连发松手时无额外步进，四档预设循环和反向区间提示正确。
- 电子木鱼连续快速敲击 50 次以上流畅无掉帧，断电重启后「累计功德」保留。木鱼应用和负一屏木鱼卡的槌头与触摸同步，音效无滞后，功德逐次增加。
- 今日运势在未校准 RTC 时显示「时间未校准 · 当前为演示签」；校准日期后显示准确日期，同日重启内容不变，跨日后自动更新。
- 2048 四向滑动灵敏且不触发系统退出手势；返回桌面再进入时棋盘与最高分保留；合成 2048 及无路可走弹窗正常。
- 亲戚计算器的关系键、性别切换、撤销和清空均正常响应。
- 七个应用及其子页的顶栏高 52 px，返回键 108×44 px、字号 20 px，顶栏操作键高 44 px，按下时仅有颜色反馈。左右安全边距 18 px，底部控件留出至少 20 px 手势净空。
- 时间工具每次打开显示三张大卡，下班倒计时、番茄钟剩余时间和数字时钟在首页自动更新，每个子页均可点「列表」回到首页。
- 番茄钟圆环与主按钮均可启停，运行时两侧调整键变淡且无法输入。返回桌面或切换其他应用 1 分钟再回来，剩余时间连续。
- 系统设置以 2×2 实时状态卡启动，亮度、音量、有效时间与电量和实际状态一致。点击或拖动 44 px 滑轨即时调节亮度和音量；点击开关行的文字、空白区和开关均可切换；恢复默认需要二次确认。
- 离线校准默认选中「分」，四颗步进键的短按、长按和松手行为正确，保存后 RTC 与桌面时间一致。
- 大卡片的纯白或纯色区域无近白渐变色带及粉黄偏色，硬币停住后币面均匀。

### 上下班时间与 Wi-Fi 校时

- 仅写入应用分区覆盖升级后，亮度、音量、功德、下班时间及 2048 存档保留，上班时间默认 09:00。保存新班次并断电重启后两个时间均能恢复。
- 两个时间入口打开的滚轮默认聚焦对应时间。分钟快选、±5 分和四套班制预设可用；取消改动后原班次有效；下班早于或等于上班时保存有提示。
- 班次设为 09:15–18:20，分别校准到 09:14、09:15、18:19 和 18:20，时间工具与负一屏的倒计时、状态和进度正确。
- iOS 与 Android 原生相机扫码加入 `DeskBuddy-XXXX` 后自动弹出配网页，浏览器直接打开 `http://192.168.4.1/` 也可用。「同步手机时间」按 UTC+8 写入 RTC，热点随后关闭。
- 手机网页可选择含中文或特殊字符的 2.4 GHz 热点，也可手填隐藏热点。错误密码有失败反馈，原已保存网络继续可用。连接成功后显示 SNTP 来源与时间，随后关闭 Wi-Fi。
- 设备扫描列表可连接开放热点和加密热点，密码键盘的大小写、数字、符号、清空和显示密码切换正常。刷新列表后返回扫码页能重新启动热点。
- 返回配网主页、退出设置、切换到扫描列表或空闲 5 分钟时热点关闭。多次配网退出或连接失败后，串口有 `Wi-Fi stopped`，内部 SRAM 无逐轮下降。
- 已保存网络且开机自动校时开启时，用未校准或跨日的 RTC 启动，桌面就绪后只尝试一次校时。关闭开关或上次同步在当天时，开机保持离线。

### 外设与稳定性

- QMI8658 摇一摇在随机实验室工具页稳定触发，大宫格首页忽略摇晃，日常拿放不误触发，2048 与亲戚计算器内不触发。
- PCF85063A 写入时间后彻底断电，再上电仍保持正确时间。
- AXP2101 电量百分比与充电图标在接拔 USB 与锂电池时准确更新。
- 外接扬声器接到板载 `SPK (P10)` 后，木鱼、硬币、骰子和完成提示音清晰无爆音，静音开关与音量滑块即时生效；未接扬声器时系统正常运行。
- 无操作 30 秒自动降亮，90 秒自动熄屏，熄屏后首次触摸只唤醒、不触发底层按钮。
- 连续切换 7 个应用 30 轮以上，串口日志中 SRAM 和 PSRAM 空闲内存无持续下降，无看门狗复位或 LVGL 异常。
